# Contributing

Thank you for contributing.

## Directory Structure

Each contribution must be placed in its own directory.

Example:

```text
univpn-route-fix/
├── README.md
└── fix-univpn-route.ps1
```

## Requirements

Every contribution must:

1. Be contained within a dedicated directory.
2. Include at least one executable script.
3. Include a `README.md`.
4. Explain:

   * What problem it solves
   * How to use it
   * Any known limitations

## Documentation Language

Documentation may be written in any language.

If the documentation is not written in Chinese or English, an additional translation must be provided:

* `README_zh.md`, or
* `README_en.md`

Examples:

```text
README.md           # Chinese
```

```text
README.md           # English
```

```text
README.md           # Japanese
README_en.md        # English translation
```

## Notes

Do not place scripts directly in the repository root.
